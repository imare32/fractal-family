# 分形家族（Fractal Family for Blender）

[![Blender Extensions](https://img.shields.io/badge/Extensions-Fractal_Family-blue?logo=blender)](https://extensions.blender.org/add-ons/fractal-family/) ![Blender Version](https://img.shields.io/badge/Blender-4.2%2B-orange) ![License](https://img.shields.io/badge/License-GPL-green)

[English](README.md) · 简体中文

分形家族用一小串复整数生成分形曲线。它的思路来自 [Jeffrey Ventrella 的研究](http://www.fractalcurves.com/familytree/)：家族树上的每一条曲线都由一个简短的**基因**描述，而分形就是这个基因把自身的替换规则反复套用之后长成的样子。

面板位于 **3D 视图 → 侧栏（`N`）→ Fractal / 分形**。

## 它做什么

一个**基因**是一串复整数，每一段还带两个变换标记。每一段说的是"下一份曲线副本放在哪儿"，标记则说明这份副本是否反向、是否镜像。把替换规则作用在一条直线上一次得到第 1 级；把规则作用在*那个结果*上得到第 2 级，以此类推。结果是一条 **teragon（分级折线）**——穿过所有等级的那条折线。

支持两种点阵：

- **高斯（`G`）**：方点阵，复整数写作 `a + bi`。
- **艾森斯坦（`E`）**：三角点阵，写作 `a + bω`；三叉路口、六角结构和 Gosper 一类的曲线都从这里来。

基因的总向量（面板上显示为**家族**，例如 `G(1, 1)`）说明整条曲线最后落在哪里；总向量相同的不同基因，视觉上属于同一个家族。

你能生成的东西只有两类：

1. **曲线**，每一级一条样条——适合渲染、挤出、转成网格，或者当作路径使用。**输出范围**关闭（默认）时得到当前等级的一条样条；打开后可以每一级一个对象，或者勾上**合并为一个对象**，用一个对象的每级一条样条装下全部等级。
2. **形态键**——一个对象，基础形状是初始折线，每级一个形态键，于是拖动**形态键时间**就能让分形长起来。这是本插件的主打功能：整段分形生长动画，就是一个曲线对象。

设计基因的整个过程中你完全不用生成任何东西：**视口预览**用即时模式绘制当前等级，输入或拖动时所见即所得。

## 安装

从 Blender 扩展平台安装（编辑 → 偏好设置 → 获取扩展），或者用本仓库打出的 `.zip` 走*从磁盘安装*。需要 Blender **4.2 LTS** 或更高版本。

## 使用指南

### 快速开始

1. 在 3D 视图侧栏打开 `Fractal` 标签页。
2. 选一个**预设**——下拉菜单按家族分组，例如 `E(3, 2) Gosper Island`。
3. 设置**等级**（默认 4），然后点**生成曲线**；或者点**生成形态键**拿可以变形的版本。

请在**顶视图**（`Numpad 7`）下操作：曲线生成在 XY 平面上。

### 基因

- **A / B**——一段的复整数分量（`G` 域里是实部和虚部；`E` 域里是 `1` 和 `ω` 的系数）。
- **R（反向）**——这一段放入的上一级曲线首尾反向。
- **M（镜像）**——这一段放入的上一级曲线镜面翻转。
- 列表是有序的：曲线从原点出发，按列表显示的顺序依次走过各段。拖动行可以上下调整顺序。
- **复制基因 / 粘贴基因**以纯文本字符串交换基因，例如 `G 1 0 0 0 0 1 1 0`。粘贴格式不对时，当前基因保持原样。
- 基因至少要两段，不能有零长度段，总向量也不能为零——否则面板会直接告诉你哪儿不对，而不是继续生成。

列表下方的**家族**标签（`G(2, 1)`、`E(1, 0)`……）就是基因的总向量：它告诉你曲线在哪里结束，也告诉你在哪个曲线家族里。

### 等级与预览

**等级**是你正在编辑、正在看的那一级；HUD 上的滚轮改的也是它。第 0 级是初始折线，第 1 级是基因本身，再往上每一级都把每一段换成完整的上一级。

**视口预览**会在编辑时把这个等级直接画在视口里。它不需要点生成，也不创建任何对象。它的深度由点数预算限制而不是固定值，所以简单的基因能画到很深，密集的基因会早一些停下：两段的基因（比如 Dragon Curve）能预览到第 16 级，五段的基因大约第 7 级，九段的基因大约第 5 级。当预览不得不在低于目标等级处停下时，面板会说明。

面板顶部的**预览**开关控制绘制开或关，默认关闭。**配色**在"每级一种固定颜色"和"统一使用你选的颜色"之间切换。

### 初始形状

第 0 级的形状，就是第一次替换所作用的那个东西：

- **直线**（默认）——从原点到总向量。
- **正三角形 … 正八边形**——闭合正多边形，边长由总向量推出来，所以像 Koch 雪花、闭合的 Gosper 岛这类闭合分形不用手工搭曲线。
- **自定义曲线**——任意曲线对象的第一个样条（忽略对象变换）。

**反向初始折线方向**会把初始形状倒过来读。对直线来说，这意味着分形从总向量往回长到原点（同一个形状转了半圈）；对多边形和自定义曲线来说，它翻转的是曲线生长的方向，雪花"向内长"的变体就是这么来的。

### 输出：曲线还是形态键

**生成曲线**把当前等级（或输出范围）写成一个曲线对象，每一级一条样条。点数随等级指数增长（`段数 × 基因段数 ^ 等级`），所以生成是在**由本机推导出的预算**内进行的：一部分来自当前真正可用的内存，一部分来自测一次就记在偏好设置里的速度标定。在一台正忙着的 8 GB 笔记本上大约是 170 万点，在工作站上 500–600 万点。面板会同时显示这个上限，以及你即将生成的等级要花多少——`第 6 级 · 1 000 001 点 · 约 0.15 s · 约 260 MB`，在你按下按钮之前就能看到。

预计超过三分之一秒的生成会**分步进行**，进度条就出现在**原来两个生成按钮的位置**——同一个框里，反馈紧挨着你刚点的按钮，而不是跑在窗口另一端的状态栏。它显示 `正在生成：第 12 / 22 级 · 55%`，下面一行 `按 ESC 可取消`，按 `ESC` 就停下并删掉已经写了一半的东西。点全部写完时**进度条消失**，换成一行文字（`点已写完 · 正在准备视口：4,194,305 点`）：Blender 自己的求值是一次不可分割的操作——一个原子的 C 调用，那段时间窗口连重画都做不到——所以它没有诚实的百分比可报，而一条停在 100% 的进度条只会被读成「已经完了，怎么还没动静」。陈述事实不会错，伪造百分比会。曲线是边展开边逐级写进去的，所以峰值内存只有「当前这一级 + 曲线本身」，而不是整条等级链——大约是先前的**一半**，同样的预算因此能生成到更高级。最后一段等待是 Blender 自己的：生成返回之后依赖图还要对新曲线求值，那一段 Python 里插不进去。

生成只写出你要的曲线，不会隐藏、转换或移动它。重的曲线就是重的曲线——环绕观察、渲染，或者用 Blender 自己的工具把它藏起来，都由你决定。

预算**是推算出来的，不是选出来的**，它只回答两个问题：可用内存够不够（取四分之一，再扣掉一点余量），以及等待是否还说得过去（十秒，含求值）。**只有这两条会让等级被降低。** 十秒是刻意放宽的——等级是你自己填大的，等待就是你要的；而且超过三分之一秒的构建已经是带进度条、可 `ESC` 中止的分步任务，那是可见的等待而不是卡死。没有额外的点数上限：机器够快、内存够，就有资格生成你请求的那一级。插件里没有任何预算设置——*状态*区直接印出算出来的那个数（`45.5 GB 可用 · 上限 6,622,516 点`），它也是某一级被降低的原因。等级字段对所有人都到 24 级；生成会在点数预算内写到最高的那一级，并告诉你写的是哪一级。

**要得比预算多不算错误**：生成会按"够得着的最高一级"执行并告诉你（`写入了第 20 级，不是第 24 级`）。对象名写的是它实际装着的等级，原始请求留在对象的 `fractalfamily_requested_level` 属性里。如果确实想要完整的，那条提示旁边的**仍然生成第 24 级**一键照做——那个按钮只存在于这条提示里，再加一个确认框毫无用处，而它是唯一可能把 Blender 卡住的路径。

**生成形态键**写出一个会变形的对象：基础形状是初始折线，第 1 级到最后一级各成为一个键，给**形态键时间**（Evaluation Time）打关键帧，分形就从一条直线长成曲线。各级做了细分，让所有键的顶点数一致。无论输出范围怎么设，形态键总是覆盖全部等级。

形态键单独计预算，因为每个键都是整条曲线的一份完整拷贝（开销 ≈ 等级数 × 点数）：预算算的是**键点总数**，不是每键点数，所以工作站上 Dragon 能到第 16 级，小机器会更早停下。触发上限时面板会说明形态键实际到第几级；形态键的样条批量写入，所以那个上限区间的上端仍然可用。

**样条**开关决定每条样条的写法：*多段线*（直线段）或*平滑*（自动手柄的贝塞尔）。

**输出范围**（默认关闭）一次写出多个等级。打开后出现两个字段，起始等级默认 1。除非勾了**合并为一个对象**，每一级都会成为独立对象；勾上之后整段范围装进一个对象，每级一条样条，低等级在前。

每次点生成都会新增一个对象。名字被占用时 Blender 会加上 `.001`，已经存在的东西一律不改，所以之前加的材质、修改器或动画都还在。

### 在视口里编辑（HUD）

点面板顶部的 **HUD**，就可以直接在视口里改基因；面板开着时按钮保持按下状态，再点一次收起。面板出现在**左下角，并且在 Blender 自己的“调整上一步操作”面板之上**，两者不会互相遮挡；抓住标题栏可以拖到任意位置。标题栏上的 `?` 按钮会打开一张说明卡，操作与下同：

| 操作 | 结果 |
| --- | --- |
| 拖动节点 | 移到另一个格点（始终吸附） |
| 点线段上的 `R` / `M` | 切换该段的反向 / 镜像标记 |
| `滚轮` | 换等级 |
| `Shift` + `滚轮` | 缩放 HUD 点阵 |
| `Tab` 或 `Q` | 在高斯 / 艾森斯坦域之间切换 |
| `A` | 追加一段 |
| `X` 或 `Delete` | 删除最后一段 |
| `F` | 重新取景 |
| `Esc`、右键或 `×` | 关闭 HUD |
| 拖标题栏 | 移动面板 |

HUD 不会抢占视口：只有指针停在面板上时才接管按键和点击，其他区域的框选、导航和快捷键照常工作。

### 场景预设

**场景预设**用一台正交俯视相机把**选中的**曲线框进画面，设置 2048×2048 渲染和 Standard 色彩变换，这样渲染出来的颜色和视口里看到的一致。什么都没选时，它退回到对当前预览取景。

### 对象命名

生成的对象按等级范围、初始形状和基因家族命名；如果用的是没改动过的预设，还会把预设名接在后面：

```
Fractal L4 Line G(1, 1) Dragon Curve
Fractal L2-4 6gon-rev E(2, 1)
Fractal L1-5 Keys Line G(1, 1) Koch Curve
```

名字只是个标签，不是指纹：同一家族里两个不同的基因，只要范围与初始形状相同，生成的名字就一样（后来那个带 `.001`）。

## 本地化

面板和 HUD 跟随 Blender 的界面语言（已包含简体中文）。如果 Blender 自带的 CJK 字体不可用，HUD 会退回英文标签。

## 权限

只声明了一项权限：**剪贴板**，用于*粘贴基因*。除非你按下*复制基因*，否则不会往剪贴板写任何东西。

没有声明 `files` 权限，因为插件**完全不做文件系统访问**——它只生成几何体，到此为止。要把点变成文件，那是 Blender 或你自己的事，现成的导出手段很多。

插件还会向操作系统查询可用内存，用来决定生成预算（见上面的*输出*一节）。这个数值只在本地使用，不会发送到任何地方，也不涉及任何网络访问。

实测的速度系数是普通的插件**偏好设置**，由 Blender 存进它自己的偏好文件——所以重启后还在，而插件自己不用碰磁盘，卸载后也不留下任何东西。它是插件唯一存储的东西：预算本身没有可存的设置。（*自定义曲线*选中的初始折线是通过 Blender 的数据接口读取的，不经过磁盘。）

## 已知限制

- 仅支持 XY 平面上、复整数点阵上的边替换分形。结点替换（例如标准 Hilbert 曲线）和 L 系统不支持。
- 预览画在视口里，不会出现在渲染结果中；渲染用的是生成的曲线对象。
- macOS/Metal 会忽略 1 px 以上的线宽。HUD 因此把折线画成几何体而不是 GL 线；在 3D 预览里，靠等级颜色判断层级更可靠。
- 自定义初始曲线只读第一个样条，并忽略对象变换。
- 等级很高时点数会非常多；面板会警告，但不会拦着你。
